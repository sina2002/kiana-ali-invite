# 💍 دعوت‌نامه دیجیتال نامزدی — کیانا و علی

دعوت‌نامه‌ی تک‌فایلی، لوکس و سینمایی (Black & Gold) برای میزبانی روی سرور شخصی.
بدون build، بدون فریم‌ورک — فقط یک `index.html`.

## ✨ امکانات

- **دروازه‌ی ورود:** گرفتن نام مهمان و شخصی‌سازی کل دعوت‌نامه با نام او
- **لینک شخصی برای هر مهمان:** `https://your-domain.com/?to=سارا`
- **پیش‌درآمد ذره‌ای:** دو پیکر از غبار طلایی شکل می‌گیرند، به هم می‌رسند و یک قلب تپنده می‌سازند
- **پاکت سینمایی:** مُهر وَکس که ترک می‌خورد و دو نیم می‌شود، فلپ با پرسپکتیو واقعی، حرکت دوربین، بلینکِ نور روی کارت
- **تشکیل اسم‌ها از ذرات** (به سبک particle-morph)
- **RSVP داستانی:** پاسخ مهمان تبدیل به نامه می‌شود، داخل پاکت می‌رود و مُهر می‌خورد — «منتظرت هستیم»
- صدای وَکس و امبینت (WebAudio)، پیش‌فرض خاموش
- پشتیبانی از `prefers-reduced-motion`، fallback بدون GSAP، بهینه برای موبایل

## 🚀 راه‌اندازی سریع

فایل `index.html` را روی هر هاست استاتیکی آپلود کنید (HTTPS لازم است — فونت‌ها و GSAP از CDN می‌آیند). همین.

## ⚙️ تنظیمات

ابتدای `<script>` در `index.html`:

```js
var CONFIG = {
  rsvpEndpoint: "",   // مثلا "https://your-domain.com/server/rsvp.php"
  musicUrl: "",       // مثلا "assets/music.mp3" — با fade-in پخش می‌شود
  figureImages: {     // PNG سیلوئت با پس‌زمینه شفاف (اختیاری)
    left:  "",        // مثلا "assets/silhouettes/ali.png"
    right: ""         // مثلا "assets/silhouettes/kiana.png"
  }
};
```

## 📬 ثبت پاسخ‌ها (RSVP)

دو نمونه‌ی آماده در پوشه‌ی `server/`:

- **PHP** — `server/rsvp.php` را آپلود کنید و آدرسش را در `rsvpEndpoint` بگذارید. پاسخ‌ها در `rsvp-data.jsonl` کنار همان فایل ذخیره می‌شوند. مشاهده‌ی لیست: `rsvp.php?list=رمز-داخل-فایل` (حتماً رمز را عوض کنید!).
- **Node.js** — `node server/rsvp-node.js` (پورت 3000).

فرمت ارسالی از سایت: `POST` با بدنه‌ی JSON:

```json
{ "name": "سارا", "message": "مبارک باشه!", "ts": 1756000000000 }
```

```
│   ├── rsvp.php          ← بک‌اند نمونه (PHP)
│   └── rsvp-node.js      ← بک‌اند نمونه (Node)

```
