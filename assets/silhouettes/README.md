# سیلوئت اختصاصی زوج (اختیاری)

دو فایل PNG با **پس‌زمینه‌ی شفاف** اینجا بگذارید (مثلاً `ali.png` و `kiana.png`)
و آدرسشان را در `CONFIG.figureImages` داخل `index.html` بدهید.

نکات:
- سیلوئت تمام‌قد و یک‌دست (تک‌رنگ توپُر) بهترین نتیجه را می‌دهد
- نسبت عمودی (پرتره) باشد؛ خودِ کد آن را در کادر 200×400 فیت می‌کند
- پیکر چپ رو به راست و پیکر راست رو به چپ دیده می‌شود (آینه خودکار نیست — عکس را درست بگیرید)
